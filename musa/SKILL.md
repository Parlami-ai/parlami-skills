# 🧩 DECISION FRAMEWORKS

## When to Refresh Creative

**Refresh if:**
- CTR drops >15% from peak (ad fatigue)
- Creative has been running >3 weeks (diminishing returns)
- Annunci requests refresh (performance decline)
- Seasonal change (Chinese New Year, back-to-school, etc.)
- New competitor creative outperforming ours (Faccia reports it)

**Don't refresh if:**
- CTR is stable and meeting targets (>3.5%)
- Creative is <2 weeks old (not enough data)
- Only minor performance dip (<10%)

## Which Photos to Use

**Prioritize photos with:**
- Children actively engaged (learning, playing, creating)
- Close-ups of faces (emotional connection)
- Diversity (multiple ethnicities, ages, genders)
- Language learning visible (teacher speaking Mandarin, Spanish words on board)
- Authentic moments (not staged, stiff poses)

**Avoid photos with:**
- Blurry images or poor lighting
- Children looking bored or upset
- Cluttered backgrounds (distracting)
- Adults dominating the frame (focus on kids)
- Any child whose parents haven't given photo consent

## How to Handle Annunci's Feedback

**If Annunci says:**
- **"CTR too low"** → Test bolder headline, brighter colors, stronger CTA
- **"Not converting"** → Emphasize trust signals (5-star reviews, years in business, certifications)
- **"Need more variety"** → Create 3-5 variations per brief (different photos, layouts)
- **"This worked great"** → Document what made it successful, replicate pattern

**Response template:**
"Acknowledged. Will test [specific change]. Expected delivery: [date]. Will track CTR and report back."

## When to Escalate to Luciano

**Escalate if:**
- Canva API down for >4 hours (can't deliver creatives)
- Photo permissions issue (parents request photo removal)
- Brand guidelines conflict (Annunci wants something that breaks rules)
- Creative consistently underperforms despite multiple iterations (deeper issue?)
- Deadline impossible to meet due to resource constraints

## 📚 Operational Knowledge (Distilled from Training)

### Key Rules — Creative That Converts
1. **Real photos > stock photos ALWAYS:** Parents detect fake instantly. AI/stock images get devalued by algorithms. Maestro's Feb 22 rule: authenticity over polish.
2. **GMB photos are weekly non-negotiable:** Add 2-3 new photos per school per week. Recency matters for algorithm. Interior, exterior, team, students, activities.
3. **PMax requires asset volume:** 15+ headlines, 5 descriptions, 20+ images per asset group. Below this = handicapped algorithm performance. More assets = better AI optimization.
4. **Meta text goes OFF images:** Facebook/Instagram penalizes text on images. Use primary text field, keep images visual-only.
5. **Message match across platforms:** Google PMax headline 30 chars, Meta 27 chars. Adjust but keep core message consistent.
6. **Reels get 36% more reach:** Instagram prioritizes Reels > Carousels > Static. 15-30 seconds optimal, hook in first 3 seconds, vertical 9:16 format.
7. **Color psychology is contextual:** Yellow/orange = childhood/creativity (great for preschools). Blue = trust/safety (parent messaging). Apply 60-30-10 rule.
8. **Video specs vary by platform:** YouTube needs 16:9, Reels need 9:16, Google PMax wants all 3 ratios. Shoot wide, crop for each.
9. **Images without width/height = CLS disaster:** Always export with proper dimensions. Hero images need fetchpriority="high".
10. **Typography hierarchy saves conversions:** Headlines 2-3x body size. Max 2 fonts per design. Left-align for readability (Western languages).

### Anti-Patterns — Creative Mistakes
- ❌ **Never use AI-generated children/classroom images:** Uncanny valley effect. Parents want to see REAL kids at YOUR school, not perfect stock children.
- ❌ **Never launch campaigns without video:** Google auto-generates terrible videos if you don't provide. Coordinate with Regista first.
- ❌ **Never ignore platform-specific specs:** Meta 20% text rule gone, but algorithm still deprioritizes text-heavy images. Each platform has preferences.
- ❌ **Never use generic CTAs:** "Learn More" < "Schedule Your Free Tour." Specific action language drives conversions.
- ❌ **Never forget mobile preview:** 80% view on phones. That beautiful desktop design might be illegible at mobile size.
- ❌ **Never skip compression:** Images >200KB = slow load = bounce. WebP for web, JPEG for compatibility, PNG only when transparency needed.
- ❌ **Never mix creative formats in test ad sets:** Reels vs static images = unfair comparison. Algorithm favors video, skewing results.
- ❌ **Never create without brand guidelines:** Both schools need distinct visual identity. Don't make Beibei look like Amici or vice versa.
- ❌ **Never skip alt text:** Accessibility + SEO signal + AI systems read images via alt text. Describe image purpose in context.
- ❌ **Never launch without photo releases:** Images of children require signed releases from parents. Legal compliance mandatory.
