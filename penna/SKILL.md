# 📊 CONTENT REFRESH ROI FRAMEWORK

**Not all content needs to be new.** Refreshing old posts can be MORE valuable than writing new ones.

## When to Refresh vs. Write New

**Refresh if:**
- Post ranked top 10 but dropped to page 2-3 (reclaim ranking)
- Post has backlinks but outdated info (preserve link equity)
- Keyword still has 200+ searches/month (demand exists)
- Post has <5% CTR in Google Search Console (improve title/meta)

**Write new if:**
- No existing post targets this keyword
- Topic is trending/seasonal (new demand)
- Competitor ranking with weak content (opportunity to outrank)

## Refresh Checklist

1. **Update publish date** (signals freshness to Google)
2. **Add 200-300 new words** (deepen coverage)
3. **Add recent statistics** (2025-2026 data)
4. **Improve meta title/description** (boost CTR)
5. **Add internal links to new pages** (cross-link recent content)
6. **Add FAQ section if missing** (capture featured snippets)
7. **Optimize images** (compress, update alt tags)
8. **Re-submit to Google Search Console** (request re-crawl)

**Expected ROI:**
- 50% less effort than new post
- 30-50% traffic boost within 30 days
- Better ROI for established domains

**Coordinate with Spia:** Monthly request for "content refresh opportunities" (posts on page 2-3 that could rank higher).

# 🚨 CRISIS PROTOCOLS

**ModSecurity Blocking Large POST Requests:**
- **Symptom:** WordPress API returns 403 Forbidden when publishing long posts
- **Workaround:**
  1. Create draft post via API (small payload, no body content)
  2. Update draft with full content (second API call)
  3. Publish (third API call)
- **Permanent fix:** Request Maestro to whitelist WordPress REST API in ModSecurity

**Post Not Indexing (Google Search Console):**
1. Check robots.txt (is blog blocked?)
2. Check WordPress SEO plugin (is post set to "noindex"?)
3. Check internal links (is post orphaned? No links pointing to it?)
4. Request indexing via Google Search Console
5. If still not indexed after 7 days → Escalate to Architetto (technical SEO issue)

**Keyword Cannibalization (Two Posts Competing for Same Keyword):**
1. Identify which post ranks higher
2. 301 redirect weaker post to stronger post
3. Merge content if both have valuable info
4. Consolidate link equity

**Content Drought (Missed 2+ Weeks of Publishing):**
1. Never let this happen (consistency is critical for SEO)
2. If unavoidable (system outage, blocker):
   - Publish 2 posts in one week to catch up
   - Notify Luciano (track why it happened, prevent recurrence)

## 📚 Operational Knowledge (Distilled from Training)

### Key Rules — Content That Converts & Ranks
1. **Topic clusters > individual posts:** Pillar page (2,000-5,000 words) + 8-10 supporting posts. Internal link EVERY post back to pillar. Signals topical authority to Google.
2. **FAQ sections mandatory for AEO:** Every post needs FAQ with question-based H2s. Direct answers in first 1-2 sentences. Add FAQ schema markup. AI Overviews pull from these.
3. **Hook → Preview → Body → FAQ → CTA structure:** Hook addresses pain point (2-3 sentences), preview sets expectations, body delivers value, FAQ catches remaining questions, CTA drives action.
4. **Match search intent or fail:** Informational ≠ transactional. "What is Montessori?" needs education, not "Book a tour!" Parent journey: awareness → consideration → decision.
5. **E-E-A-T signals mandatory for AI citation:** Experience (teacher quotes), Expertise (Maestro's credentials), Authoritativeness (research citations), Trustworthiness (reviews, accreditations).
6. **Readability: 6th-8th grade level:** Parents scan on phones during work breaks. Short paragraphs (2-3 sentences), active voice (90%+), contractions for conversational tone.
7. **Historical optimization > new content:** Update posts ranking 11-20 (striking distance). Add fresh data, improve structure, internal links. Faster results than new posts.
8. **Message match for paid traffic:** If Annunci's ad says "Free Tour," blog CTA must say "Free Tour" (not "Learn More"). Consistency drives conversion.
9. **Story framework drives engagement:** Character (parent) + Conflict (choosing preschool) + Resolution (our school). Write from parent's perspective, not school's.
10. **Promotion = content creation time:** Great content unseen has zero impact. Tailor promotion per platform: Facebook (community), Instagram (visual), GBP (local).

### Anti-Patterns — Content Killers
- ❌ **Never write without keyword research:** Beautiful prose ranking for nothing = wasted effort. Target specific long-tail keywords parents actually search.
- ❌ **Never stuff keywords unnaturally:** "Montessori Phoenix preschool Ahwatukee Montessori" = spam signal. Google handles synonyms; write for humans.
- ❌ **Never skip internal linking:** Orphan pages get less authority. Every post links to pillar + 2-3 related posts minimum.
- ❌ **Never ignore existing content:** Audit first. Merge thin posts, update outdated info, redirect dead content. Don't create duplicates.
- ❌ **Never write features instead of benefits:** "We have certified teachers" < "Your child learns from experts who understand development." Parent-centered always.
- ❌ **Never publish without schema markup:** FAQ, LocalBusiness, Review schemas help AI systems understand and cite your content.
- ❌ **Never forget local keywords:** Parents search "preschool Arcadia" not just "preschool." Every post needs geographic relevance.
- ❌ **Never launch blog without editorial calendar:** Random posting = random results. Map content to enrollment seasons and parent journey stages.
- ❌ **Never use generic CTAs:** "Click here" < "Download our Mandarin Learning Guide." Specific action language improves conversion.
- ❌ **Never write in passive voice:** "The tour can be scheduled" → "Schedule your tour." Active voice is clearer, more engaging.
