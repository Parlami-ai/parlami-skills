# 🚨 CRISIS COMMUNICATION PROTOCOL

**Social media is public. Mistakes are visible. Have a plan.**

## Scenario 1: Negative Comment

**Action:**
1. **DO NOT DELETE** (unless profane/spam)
2. Respond within 2 hours (shows we care)
3. Acknowledge + take offline:
   ```
   Thank you for sharing your feedback. We'd love to discuss this directly and make things right. Please email us at [email] or call [phone] so we can address your concerns. We appreciate you!
   ```
4. Notify Luciano + Maestro (they may need to follow up)
5. Never argue publicly (take offline always)

## Scenario 2: Misinformation Spreading

**Example:** "I heard Beibei is closing!" (false rumor)

**Action:**
1. Respond immediately with facts:
   ```
   This is not accurate. {{SCHOOL1_NAME}} is open and thriving! We're enrolling for fall 2026. If you have questions, please call us directly at [phone]. We're happy to clarify!
   ```
2. Post a positive update (photo of happy kids, enrollment announcement) to drown out negativity

## Scenario 3: Photo Permission Issue

**Parent requests photo removal:**

**Action:**
1. **Immediately delete post** (no questions, no delay)
2. Apologize via email/phone:
   ```
   We sincerely apologize. The photo has been removed from all platforms. We've updated our records to ensure this doesn't happen again. Thank you for letting us know.
   ```
3. Update photo permissions log (mark child as "Do Not Post")
4. Notify Musa (don't use that photo in ads either)

## Scenario 4: Controversial Topic (Politics, Religion, etc.)

**Action:**
- **NEVER post political or religious content** (schools must stay neutral)
- If someone comments with divisive content:
  - Delete if spam/trolling
  - Respond diplomatically if legitimate:
    ```
    We appreciate all perspectives! Our focus is providing a welcoming environment for all families. If you'd like to discuss further, please reach out directly.
    ```

## 📚 Operational Knowledge (Distilled from Training)

### Key Rules — Social That Drives Tours
1. **Engagement > follower count:** Algorithm values comments, shares, saves. 5% engagement rate minimum (Buffer 2026 median: FB ~5.6%, IG ~5.5%).
2. **Reply to EVERY comment within 4 hours:** Replying boosts engagement: FB +9%, IG +21%, Threads +42%. This is the single biggest lever.
3. **Best times matter:** Thursday 9 AM = peak Facebook engagement. Morning hours (6-11 AM) consistently best weekdays. Saturday worst day, afternoons worst time.
4. **Consistency > perfection:** Post daily. Accounts that skip days underperform their baseline. Our 7-day schedule is correct.
5. **Format performance varies by goal:** IG Reels = +36% reach, Carousels = +12% engagement. FB formats within 1% of each other. Match format to objective.
6. **Stories build urgency:** Daily IG Stories at 3:30 PM (pickup time). Use polls, questions, countdowns for enrollment deadlines.
7. **Hashtag strategy: 5-10 max on IG:** Mix local (#ArcadiaKids) + niche (#MandarinImmersion) + branded (#BeibeiAmigos). Research before using.
8. **Social listening drives engagement:** Monitor "preschool Phoenix," competitor names, "bilingual preschool." Join conversations, don't just broadcast.
9. **Community > audience:** Build dialogue. Ask questions, run polls, feature parent spotlights. Social selling requires trust first.
10. **Platform-specific optimization:** No markdown tables in Discord/WhatsApp (use bullets). Wrap multiple links in <> for Discord. Bold for WhatsApp emphasis.

### Anti-Patterns — Social Media Mistakes
- ❌ **Never post same message across all platforms:** Tailor per platform. What works on Facebook fails on Instagram Stories.
- ❌ **Never ignore negative comments:** Silence = admission of guilt. Respond empathetically within 24 hours. Move to DM if needed.
- ❌ **Never buy followers:** Algorithm detects fake engagement. 100 real parents > 10,000 bots.
- ❌ **Never post without visual content:** Posts with images get 2.3x more engagement. Every post needs image or video.
- ❌ **Never forget platform culture:** LinkedIn = professional, Instagram = visual storytelling, Facebook = community discussion. Respect the vibe.
- ❌ **Never post during dead hours:** Saturday afternoons = worst engagement. Use scheduling tools for optimal timing.
- ❌ **Never spam hashtags:** #preschool #education #Phoenix #kids #learning #school #Montessori = looks desperate. Quality over quantity.
- ❌ **Never ignore analytics:** Weekly review of engagement rate, reach, link clicks mandatory. Adjust strategy based on data.
- ❌ **Never break platform rules:** Each platform has community guidelines. Violations = reduced reach or suspension.
- ❌ **Never go dark during enrollment season:** Spring (March-May) and fall (August-September) need doubled posting frequency.
